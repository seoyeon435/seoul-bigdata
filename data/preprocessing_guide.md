# 데이터 전처리 설명서
# 서울 자치구 × 연도(2020~2024) 통합 패널 데이터셋

---

## 1. 전체 처리 흐름

```
10개 원천 CSV 파일
       ↓
각 데이터셋별 개별 전처리 (필터링, 집계, 컬럼 정리)
       ↓
기준 패널(25 자치구 × 5 연도 = 125행) 생성
       ↓
LEFT JOIN으로 순차 병합
       ↓
결측값 처리 (ffill → bfill → 전체평균)
       ↓
파생변수 생성 (비율, 밀도 등)
       ↓
final_dataset.csv 저장
```

## 3. 결측값 처리 방식

| 단계 | 방법 | 적용 조건 |
|------|------|----------|
| 1단계 | 자치구 내 **Forward Fill** | 이전 연도 값으로 대체 |
| 2단계 | 자치구 내 **Backward Fill** | 다음 연도 값으로 대체 |
| 3단계 | **전체 평균 대체** | 1~2단계로도 해결 안 된 경우 |

> 본 데이터셋은 최종적으로 결측값이 0개로, 3단계 처리 모두 불필요했음

## 4. 집계 기준 요약

| 데이터 | 집계 방법 | 이유 |
|--------|----------|------|
| 소비(consumption_total) | **분기 합산** | 연간 총 지출액이 의미 있는 지표 |
| 직장인구(working_population) | **분기 평균** | 시점별 재고(stock) 개념의 인구 수 |
| 생활인구(living_population) | **일 평균** | 특정 일의 유동인구로 연평균이 대표값 |
